# 企业级用印治理

本模块由上海如静知华信息科技有限公司（[知华科技](https://www.zhuatech.cn/)）提供，覆盖纸质印章与电子印章的申请、复核、使用、归还和归档闭环。

## 核心控制

- 定稿审批、授权有效期、用印对象和份数联合校验。
- 申请人与印章保管人职责分离；对外用印强制法务复核。
- 实物印章归还确认、电子印章防篡改、证据与归档任务留痕。
- 按对外范围和批量份数评定风险，并返回可执行审批路径。

接口：`POST /api/enterprise/oa/seal-use`。结果为 `APPROVE`、`REVIEW` 或 `BLOCKED`，同时返回阻断项和整改动作。
